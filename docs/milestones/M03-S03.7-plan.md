## 3. Task A — summary attribution (L)
**A1 Schema v5** (`agent/schemas.py`): keep today's class as `ConversationSummaryOutputV4`; new v5 `ConversationSummaryOutput`; `output_model_for(prompt)` (v5 for prompt ≥ v5, else V4). Plain strict schema (D52): every field required, nullable where optional, `language` first.
```python
class Commitment(BaseModel):  # v5
    by: Literal["owner", "contact"]  # who is to do it
    status: Literal["promised", "agreed", "requested"]
    text: str  # only WHAT; never who promised/asked/to whom
    due: str | None
    message_ids: list[int]
```
`SummaryPoint.text`: only the question/decision/fact itself, never who asked (the application adds it). No new model field for questions/decisions (the list fixes the direction; the validator enforces it). "To whom" derived (1:1 chat). `sanitize` returns a `SanitizeResult` (summary, uncited, capped); stores `status` when present.

**A2 Attribution validator** (new pure `agent/attribution.py`): `check_attribution(summary, authors: Mapping[int, str]) -> (summary, AttributionCounts)`.
- Sides: owner = `owner_manual` + `assistant_sent`; contact = `contact`; `owner_automated` neutral (may be cited for key facts, never supports a promise, agreement or question).
- Open question / decision: needs ≥ 1 cited contact-side message, else drop (`misattributed_dropped`).
- Commitment by P, "promised": needs ≥ 1 cited P-side message; else if the other side is cited → `status="requested"` (catches c37, c17); else drop.
- "agreed": needs both sides cited; else demote to "promised" (P cited) / "requested" (other cited) / drop.
- "requested": needs ≥ 1 cited other-side message, else drop; never upgraded.
- Legacy items (no `status`) = "promised". Ids with unknown author ignored; an item whose ids are all unknown is kept unchanged (legacy read only).
- Demote rather than drop (keeps real open loops; "requested" states only what the citations prove).
- Runs at write time (in `Summarizer` after `sanitize`, rolling and period) and at read time (in `summary_view`, for all stored rows incl. v1–v4 in production). Counts logged only.

**A3 Rendering** (`agent/attribution.py`): `render_who(list_key, item, contact_name, locale)`, `you_word(locale)`, fixed templates per `SupportedLocale` (avoid case suffixes and gendered verbs on names). Missing name fallback: en "the contact", uz-Latn "suhbatdosh", uz-Cyrl "суҳбатдош", ru "собеседник". ## 4. Task B — retrieval product (M–L)
**B1 Widening** (`memory/retrieval.py`, `agent/tools/search.py`): `search_messages(..., widen_empty_scope=False)`: if a contact/conversation-filtered search has no hits, search again without those two filters (keep dates, directions, account scope); `SearchResult.widened = True`.
