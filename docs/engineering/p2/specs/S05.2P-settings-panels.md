## Design

**/settings main screen** gains one row: `("Alerts & digest…", "alerts")`. Pressing it edits the message into the alerts screen (same pattern as `"replies"` → `reply_screen`).

**Alerts screen** (`alerts_screen(session, clock, account) -> Screen`, kind `ALERTS_CARD`). Text (HTML, escape nothing user-typed because nothing user-typed is shown):
```
<b>Alerts & digest</b>

Quiet hours: <current or "off">   (urgent alerts wait too, unless "Urgent bypass" is on)
Urgent bypass: <on|off>
Daily digest: <HH:MM or "off">
Most alerts per hour: <n>
Times are in your timezone (<account.timezone>).
```
Rows (each current value ticked with `_ticked`), ops kept ≤ 12 characters:
- Quiet hours: `Off` (`q_off`), `22–07` (`q_2207`), `23–08` (`q_2308`), `00–08` (`q_0008`)
- Urgent bypass: `Bypass on` (`b_on`), `Bypass off` (`b_off`)
- Digest: `Off` (`d_off`), `08:00` (`d_0800`), `12:00` (`d_1200`), `18:00` (`d_1800`), `21:00` (`d_2100`)
- Cap: `3/h` (`c_3`), `6/h` (`c_6`), `10/h` (`c_10`), `20/h` (`c_20`)
- `◀ Back` (`back`)

**`_press_alerts`**: map the op to a preference change, call `preferences.update(session, account, <key>=<value>, actor="owner", clock=clock)` (F0 adds these keyword arguments — see "When to stop and ask"), re-render `alerts_screen`, `_after_press(..., answer="Saved", edit=screen)`. `back` → `settings_screen`. Unknown op → `CALLBACK_EXPIRED_TEXT` (same as `_press_reply`). The digest schedule itself is updated by S05.3b's reconciler from the stored preference within a minute; you do not touch schedules.

**Conversation panel priority row**: `panel_rows` stays synchronous and appends `[("VIP", "p_vip"), ("Normal", "p_normal"), ("Low", "p_low")]` with `panel.contact_priority` ticked. F0 adds `contact_id` and `contact_priority` to `ConversationPanel` (`conversations/visibility.py`, R14), so everything you need is already on the panel object — you never edit `visibility.py` and never make `panel_rows` async. Not for a bot chat (`panel_rows` already returns `None` for those). `_press_panel` handles `p_*`: call `conversations.priority.set_priority(session, account_id=account.id, contact_id=panel.contact_id, priority=<value>, actor="owner", clock=clock)`, re-render the panel, answer "Saved". A foreign or unknown contact raises `NotInAccountError` (a `LookupError`, which the panel already catches) → answer `CALLBACK_EXPIRED_TEXT`.
