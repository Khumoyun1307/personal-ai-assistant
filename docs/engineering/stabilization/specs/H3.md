| Item | Specification |
|---|---|
| Goal | Dictation/literal edits copy validated owner source characters across turns. |

|---|---|
| H3-1 | `propose_message` accepts C2 source IDs, loads spans in account/request, verifies role/purpose/field hash/bounds and copies slices; current clarification need not contain dictated text. |

| H3-4 | Missing, purged, changed, forwarded, quote, assistant, command-framing or foreign sources cannot be owner literal body. Do not redirect failure to generic regeneration; preserve request/report missing source. |
| H3-5 | Explicit assistant suggestion selection uses its exact scoped artifact source plus owner selection proof; remains generated, never owner_dictated. |
| H3-6 | Exact retry no effect; different proposal returns conflict, including changed sources/target. Old current-turn-only tests change only with dated D-S2 supersession. |
